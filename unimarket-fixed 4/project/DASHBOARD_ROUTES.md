# Dashboard previews connected to app routes

The dashboard previews now map to the live server-rendered pages:

- Buyer preview: `/buyer`
- Seller preview: `/seller`
- Admin preview: `/admin`
- Shared orders and delivery: `/orders`
- Shared reports: `/reports`

The authenticated sidebar exposes the dashboards the current account can access. Buyer, seller, and admin login redirects remain role-specific.
